# Blinker 0.1.3 — release preparation

Status: draft, not published. This release includes PR #5 and the follow-up security hardening.

## User-visible changes

- Detect quoted SSH routing and forwarding options.
- Hide raw command arguments from real request tooltips, history and CLI output.
- Explain that Stop requests client termination; keep a don’t-touch warning until the hardware wait ends.
- Skip unsafe git metadata paths rather than resolving symlinks into protected or remote locations.
- Verify the signed version name as well as its signature; prevent accidental downgrades.
- Provide inspectable installation instructions pinned to the reviewed installer.

The app remains a notifier, not an authorization boundary. No key policies or SSH/GPG settings change.
